# Usage Mirror Notice

`Qingyu_backend/docs/guides/usage` 当前是 `Qingyu_backend/docs/usage` 的历史镜像目录。

## Current Rule

- 当前使用类文档的 canonical 入口优先看 [../../README.md](../../README.md) 和 [../README.md](../README.md)。
- 如果你在找具体使用说明，请优先去 `Qingyu_backend/docs/usage/` 查找原始文件。
- 不要继续在 `docs/guides/usage/` 新增、复制或修改同名使用文档，避免双写。

## Why

- 本目录与 `docs/usage/` 当前文件集合完全重复。
- 继续双写会让后续人工维护和 AI 检索都难以判断哪份才是最新版本。

## Next Step

- 后续应在确认所有引用路径后，将本目录收口为迁移提示或整体归档。
