# 后端测试标准入口

> 最后整理: 2026-05-22

## 当前入口说明

- 本目录负责测试标准、分层约束和少量底层工具约定。
- 具体测试报告、测试执行说明和阶段结论请回看 [../../testing/README.md](../../testing/README.md)。
- 历史 README 中曾引用大量尚未落地的 `02_测试类型规范/`、`05_最佳实践/`、`06_快速参考/` 子目录；这些目录当前不存在，已从主入口移除。

## Boundary Rule

- `../../testing/` 回答“怎么跑、跑了什么、某次验证怎么复现”。
- `./` 回答“测试必须遵守什么规则、各层应该如何测试”。
- `../../test/` 是仓库根层测试源码目录，不是文档目录。
- `../../docs/test/` 是历史文档路径，只保留迁移说明。

## 落盘规则

1. 新增测试标准前，先确认它是否真的是“长期规则”，而不是一次执行记录。
2. 执行记录、测试报告、快速排障说明不要写进本目录，应回到 [../../testing/README.md](../../testing/README.md)。
3. 不要把源码路径 `../../test/...` 误写成 `../../docs/test/...`。
