# 服务启动指南

> 最后整理: 2026-05-22

本文档只负责“本地如何启动后端并完成基础联调”，不承担完整运维或生产部署说明。

## Current Rule

- 后端本地开发默认使用 `air -c .air.toml` 热重载启动。
- 仅在热重载本身需要排查或用户明确要求时，才退回 `go run cmd/server/main.go`。
- 生产部署、监控、CI/CD 与性能优化，请回到 [../ops/README.md](../ops/README.md)。

## Local Startup

### 1. 启动后端

```powershell
cd "E:\Github\Qingyu\Qingyu_backend"
air -c .air.toml
```

预期监听端口：

- `http://localhost:9090`
- API 基础路径：`http://localhost:9090/api/v1`

如果本机还没有安装 `air`：

```powershell
go install github.com/air-verse/air@latest
```

### 2. 仅在排查热重载问题时使用 `go run`

```powershell
cd "E:\Github\Qingyu\Qingyu_backend"
go run cmd/server/main.go
```

## Health Check

```powershell
Invoke-WebRequest -Uri "http://localhost:9090" -Method GET
```

如果服务已正常启动，终端中应能看到 Gin 监听日志和数据库连接相关输出。

## Common Checks

### 端口占用

```powershell
netstat -ano | findstr "9090"
```

### MongoDB 是否可用

```powershell
netstat -ano | findstr "27017"
```

### Redis 是否可用

```powershell
netstat -ano | findstr "6379"
```
